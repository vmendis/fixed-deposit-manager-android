Recommendation

For spec compliance + low impact + your earlier Option B words+exact
  • Option A is best for V22 fix — minimal, spec says card meta shows tenor + payout, implementation is one line change in Components.kt FdCard: ${rate}% • ${tenor} • ${payout.label} • matures ${date}
  • If spacing feels tight on small screens, fallback to Option B two-line meta — same info, more breathing room, card height +14dp, still passes maxSwipes 50.
  • Avoid Option C chip for now — adds new visual element not in spec, but could be V2 enhancement for filtering by payout.
  • Update spec §4.2 to be explicit: "Each FdCard shows Rate • Tenor • PayoutFrequency • Matures" and keep Detail shows Interest payout row.
  • Tests: AddFdValidationTest already asserts tenor exists, we should add assertion for payout label exists (Monthly payout / At maturity) — new UI test.
